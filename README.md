Entry for the make.fun bounty **[One-Line Office Jokes](https://make.fun/bounty/u-markk-st-one-line-office-jokes-a51f2bcc)** — a single line that makes office life funny.

## The joke

> I replied-all to say please stop replying-all, and now there are forty-seven emails about stopping reply-all.

## How it works

`main.ts` (Node.js, standard library only) validates the line — 1–199
characters, a single line, not only whitespace — and writes it to
`output/entry.txt`. Paths are resolved relative to the source file, so it
runs from any working directory. Set `MAKEFUN_OUTPUT_DIR` to override the
output directory.

```sh
node main.ts
cat output/entry.txt
```
